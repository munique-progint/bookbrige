BookBridge

Sobre o projeto
O BookBridge é um sistema desenvolvido como Projeto Integrador, com o objetivo de facilitar o acesso e o compartilhamento de materiais educacionais entre estudantes e colaboradores.

A plataforma permite consultar conteúdos digitais, organizar materiais de estudo e disponibilizar materiais físicos para doação.

Objetivo
Promover o compartilhamento de conhecimento e facilitar o acesso a materiais de estudo, incentivando a colaboração entre os usuários.

Funcionalidades
- Cadastro e login de usuários.
- Consulta e pesquisa de conteúdos digitais.
- Filtros por categoria e nível.
- Visualização dos detalhes dos conteúdos.
- Favoritar conteúdos digitais e materiais de doação.
- Organização de conteúdos digitais em pastas pessoais.
- Publicação e gerenciamento de conteúdos digitais por colaboradores.
- Cadastro e gerenciamento de materiais físicos para doação.
- Gerenciamento da conta do usuário.

Tipos de usuários
- Visitante: pode navegar pelos conteúdos públicos da plataforma.
- Estudante: pode favoritar conteúdos e materiais de doação, organizar conteúdos digitais em pastas e gerenciar sua conta.
- Colaborador: pode publicar e gerenciar conteúdos digitais, além de utilizar as funcionalidades disponíveis aos demais usuários.

Tecnologias utilizadas
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- Docker

Banco de dados
O sistema utiliza o MySQL para armazenar informações dos usuários, conteúdos digitais, materiais de doação, favoritos e demais dados necessários ao funcionamento da aplicação.

Execução do projeto
O ambiente de desenvolvimento utiliza Docker e Docker Compose para executar os serviços necessários à aplicação.
